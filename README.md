# Governed Action Lab

A deterministic reference implementation showing that an agent's proposed
action is not authorization.

This repository is under local construction. The implementation remains
synthetic and does not execute against production systems, repositories,
networks, accounts, or private knowledge stores.

## Producer contract

The frozen public diagnostic fixture consumes `context-layer-diagnostic/v1`
from Context Layer Lab commit
`b0179a8e365ab35691864e55d5792db1bdefbcb2`.

## Development

Requires Node.js 22 or newer.

```bash
npm install
npm run check
```
